Proxy Bluetooth M5Stack Atom

Premier flash depuis le navigateur (Chrome ou Edge sur ordinateur).

  1. Branche le M5Stack Atom en USB.
  2. Clique sur le bouton ci-dessous et choisis le port série.
  3. Saisis ton WiFi quand la fenêtre le demande.
  4. Dans Home Assistant : Paramètres → Appareils → ESPHome, ajoute l'appareil découvert, puis dans le dashboard ESPHome clique sur Adopter.
  5. Complète ton secrets.yaml (voir le dépôt) et installe : le tunnel WireGuard s'active par OTA.
Ce navigateur ne gère pas Web Serial : utilise Chrome ou Edge. Web Serial exige une page en HTTPS.
